# Skill: fit-review

**Owners:** [customer-targets.md](../../docs/product/heuristics/customer-targets.md), [customer-fit.md](../../docs/product/heuristics/customer-fit.md)

Use after targets are filled for the host. Until then: mark gaps TODO; do not invent buyers.

## Efficient pass

Subject sentence (`claim:` / `feature:`). Read Who / job first, then fit ranks. Same-turn must/should when the skill is the task.

## Loop

1. Name the feature or claim.
2. Map to a Primary job or fail.
3. Apply fit ranks (job → spine → value per time → claim matches shipped). Spine = core product path the Primary job needs; see owner Fast path.
4. Present numbered forks when keep / park / cut are all valid.

## Severity

**must** = no buyer; claim without shipped behavior. **should** = off-spine weight; weak value per time.
